A SLIPERY CLIMB  v1.5.0 "SUMMIT"
================================

RUN
  Double-click "A Slipery Climb.exe".
  No installation and no Python needed.

FIRST LAUNCH
  Windows may show "Windows protected your PC" because the exe is not
  code-signed. Click "More info" -> "Run anyway".

CONTROLS
  Mouse .......... aim and throw candy
  Alt ............ toggle the cursor while playing
  Esc ............ save and return to the menu
  Space / Enter .. skip cutscene
  M .............. open / close the Free Climb map
  Right click .... teleport on the Free Climb map

NEW IN 1.5
  Free Climb: clear the mountain once in Regular mode, then explore it - a map
  of the whole climb in the top-right corner, right-click to teleport
  anywhere, achievements off, no saving.
  Profiles: several players on one computer, each with their own saves,
  achievements and "cleared" status (existing progress moves into the first
  profile automatically).
  Run timer next to the Exit button, and the game now asks before quitting.
  Esc works on every screen, all buttons are blue again, and the summit in
  Free Climb no longer traps you.

NEW IN 1.4
  Easy mode with 8 checkpoints (choose it when you create a new save),
  voice-over in 9 languages with its own volume slider, and a fullscreen /
  window switch in Settings.

WHERE IS MY DATA
  Settings, profiles, achievements and save slots are stored in:
  %APPDATA%\A Slipery Climb
  Each profile keeps its files in %APPDATA%\A Slipery Climb\profiles\

CLEARING THE GAME
  Reaching the cabin on the summit deletes that save slot, so every run
  starts fresh.

------------------------------------------------------------

ЗАПУСК
  Двойной клик по "A Slipery Climb.exe".
  Установка и Python не нужны.

ПЕРВЫЙ ЗАПУСК
  Windows может написать "Система Windows защитила ваш компьютер",
  потому что exe не подписан. Нажмите "Подробнее" -> "Выполнить в любом случае".

УПРАВЛЕНИЕ
  Мышь ........... прицелиться и бросить конфету
  Alt ............ переключить курсор во время игры
  Esc ............ сохранить и выйти в меню
  Пробел / Enter . пропустить катсцену
  M .............. открыть / закрыть карту в Свободном подъёме
  Правый клик .... телепорт на карте

НОВОЕ В 1.5
  Свободный подъём: пройди гору один раз в обычном режиме и исследуй её —
  карта всей горы в правом верхнем углу, правый клик — телепорт, достижения
  отключены, сохранений нет.
  Профили: несколько игроков на одном компьютере, у каждого свои сохранения,
  достижения и статус прохождения (старый прогресс переезжает в первый профиль
  автоматически).
  Таймер рядом с кнопкой выхода, подтверждение выхода, Esc работает на всех
  экранах, все кнопки снова синие, а вершина в Свободном подъёме больше не
  запирает игрока.

ГДЕ ЛЕЖАТ ДАННЫЕ
  Настройки, профили, достижения и сохранения: %APPDATA%\A Slipery Climb
  Данные профилей — в %APPDATA%\A Slipery Climb\profiles\

------------------------------------------------------------

运行
  双击 "A Slipery Climb.exe"，无需安装、无需 Python。

首次运行
  Windows 可能提示“Windows 已保护你的电脑”（exe 未签名）：
  点“更多信息”→“仍要运行”。

操作
  鼠标 ......... 瞄准并扔糖果
  Alt .......... 切换光标（游玩时）
  Esc .......... 保存并回菜单
  空格 / 回车 .. 跳过过场
  M ............ 打开 / 关闭自由攀登全图
  右键 ......... 在全图上传送

1.5 新增
  自由攀登：常规模式通关一次后可把整座山当沙盒玩——右上角全山地图，右键传送，
  不解锁成就，也不会存档。
  账号系统：一台电脑多个玩家，各有独立的存档、成就和通关记录
  （已有进度会自动迁移到第一个账号）。
  计时器（在退出按钮旁）、退出确认；Esc 在所有界面都能回菜单；按钮统一蓝色；
  自由攀登里山顶不再把你关住。

数据位置
  设置、账号、成就、存档都在 %APPDATA%\A Slipery Climb
  每个账号的数据在 %APPDATA%\A Slipery Climb\profiles\ 下

通关
  走到山顶小屋就会删掉该存档位，每次都是新的一趟。
