# A SLIPERY CLIMB

**A small, slippery climbing game about a Santa who has to get up a very big
mountain to deliver presents.**

### [⬇ Download for Windows (latest release)](../../releases/latest)

There is no walk button. You move by throwing candy and letting the explosions
push you around: throw backward to slide forward, blast-jump over gaps, and ride
moving platforms up the mountain.

![gameplay](screenshots/gameplay.png)

## Features

- Hand-made level in the spirit of *Getting Over It*: stairs, steep ladders,
  drop jumps, ferries, elevators and curved moving platforms
- Candy-bomb movement: throw, blast, slide, climb
- 9 languages: English, русский, 中文, 日本語, 한국어, Deutsch, Français,
  Italiano, Español
- Intro and victory cutscenes (skippable), idle chatter, leveled achievements
- 5 save slots; clearing the mountain deletes that slot, so every run is fresh

## Controls

| Input | Action |
|---|---|
| Mouse | aim and throw candy |
| Esc | save and return to the menu |
| Space / Enter | skip cutscene |

## Install

1. Open the [Releases](../../releases) page and download `ASliperyClimb_Windows.zip`.
2. Unpack it anywhere.
3. Run `A Slipery Climb.exe`. No installation and no Python needed.

> Windows may show "Windows protected your PC" because the exe is not code-signed.
> Click **More info → Run anyway**.

Settings, achievements and saves are stored in `%APPDATA%\A Slipery Climb`.
