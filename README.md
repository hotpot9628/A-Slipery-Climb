# A-Slipery-Climb
一个关于圣诞老人的小游戏：他要爬上很高的山，把礼物送到山顶的小屋。  这里没有“走”这个按钮——你只能靠扔糖果、借爆炸的反冲把自己推上去： 往后扔往前滑、往脚下扔起跳、等移动平台靠过来再搭上去。
A small, slippery climbing game about a Santa who has to get up a very big mountain to deliver presents. There is no walk button. You move by throwing candy and letting the explosions push you around: throw backward to slide forward, blast-jump over gaps, and ride moving platforms up the mountain.
Небольшой «скользкий» платформер про Санту, которому нужно подняться на большую гору и доставить подарки. Кнопки «идти» здесь нет: вы двигаетесь, бросая конфеты и подкидывая себя взрывами. Бросили назад — скользите вперёд; бросили под ноги — прыжок; дождались движущейся платформы — поехали вверх.
