三、先给旧版本打 pre-release（如果还没打）
------------------------------------------
Releases -> 依次打开 v1.4.1、v1.4.0、v1.3.0、v1.2.0、v1.1.0、v1.0.0
-> Edit -> 勾选 “Set as a pre-release” -> Update release。
这样 1.5.0 才会是第一个正式版。


四、重新发布 1.5.0
------------------
1. Releases -> Draft a new release
2. Tag:      v1.5.0      （必须带 v，CI 用它生成 deb/rpm 版本号）
   Target:   main
3. Title:    A SLIPERY CLIMB · SUMMIT — 1.5.0 (first official release)
4. 正文：把 release-notes.md 的全部内容粘贴进去
5. 不要勾 pre-release；发布后确认它是 “Latest”
6. Publish release -> Actions 里的 build 会自动跑

注意：tag 名必须是 v1.5.0 这种 vX.Y.Z 形式，否则 deb/rpm 版本号会退回 1.0.0。
不要重命名已有的 tag，旧下载链接会断。

六、更新提示怎么验证（重要）
----------------------------
发布后 1.5.0 已经是最新版，直接启动不会弹提示（这是对的）。想验证提示弹窗：
1. 在本地源码里临时把 main.py 的 GAME_VERSION 改成更小的值（比如 "1.4.9"），
   用 build.bat 打一个临时 exe，启动后应弹「发现新版本 v1.5.0」；
2. 点「打开下载页」应打开 GitHub Releases；点「稍后」本次不再提示；
   点「跳过此版本」后重启，不应再提示 1.5.0；
3. 断网启动不应报错、也不提示（静默跳过）。
（改完记得把 GAME_VERSION 改回 "1.5.0" 再上传。）

七、本次改动摘要
----------------
- 新增玩法：自由攀登（常规模式首次通关解锁，全山地图 + 右键传送，不解锁成就、
  不存档，山顶隐形墙关闭）
- 新系统：账号（每账号独立存档/成就/通关；老数据自动迁移）
- 新 UI：计时器、退出确认、版本号、圆角按钮；存档/设置/账号界面 Esc 返回
- 新功能：启动时后台检查 GitHub Releases，有新版本时主菜单提示，可一键
  打开下载页；「稍后」/「跳过此版本」；只连 api.github.com，不发送个人信息，
  不自动下载/安装，断网静默跳过
- 修 bug：自由攀登离开山顶后摩擦力恢复；山顶平台可传送；韩文/emoji 名字显示；
  输入法改中文名；损坏存档不再崩溃
- 打包：Python 3.8 + pygame 2.6.1 + PyInstaller 6.22.3，适配老电脑
- 版本号：main.py GAME_VERSION、version_info.txt、macOS plist 全部 1.5.0

八、SHA256 校验
---------------
PowerShell：
  Get-Content .\_SHA256SUMS.txt | ForEach-Object { $h,$f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash -ne $h) { "MISMATCH $f" } }
（_SHA256SUMS.txt 里记录了 1-root、store、workflow、screenshots 全部 26 个文件）
